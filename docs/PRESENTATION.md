# Видео-презентация ContractScout (7–10 минут)

Тайминг рассчитан на запись экрана: веб + (по возможности) MAX.

| Мин | Блок | Что показать / сказать |
|---|---|---|
| 0:00–0:45 | Крючок | «Подрядчику прислали договор на 18 страниц в пятницу вечером. Юриста нет. Что делать за 10 минут?» |
| 0:45–2:00 | Проблема и ЦА | Рычаги заказчика: cap нет, IP на библиотеки, правки бесконечно, оплата после акта. Аудитория — ИП и студии. |
| 2:00–3:00 | Конкуренты и УТП | Не Harvey и не «просто ChatGPT». Гибрид правил + RAG-каталог IT-рисков РФ + цитаты. Канал MAX, как в предыдущих домашках. |
| 3:00–4:00 | Архитектура | Схема из ТЗ: ingest → store → review/draft. Почему MiniLM локально и DeepSeek. Дисклеймер. |
| 4:00–6:30 | Демо проверки | Открыть веб. Загрузить `samples/risky_it_contract.txt`. Показать индекс, карточки (ответственность, IP, поручительство). Зачитать одну правку для заказчика. |
| 6:30–8:00 | Демо черновика | Заполнить бриф. Сгенерировать. Пролистать: автоприёмка, лимит, IP split. Скачать DOCX. |
| 8:00–9:00 | Расширения | MAX-кнопки, SMTP, тесты `pytest`, Docker. Что не обещаем (это не адвокат). |
| 9:00–10:00 | Итог | Репозиторий, ТЗ, демо-URL. Следующий шаг: OCR сканов и сравнение двух редакций. |

### Скрипт заключения

«ContractScout не подписывает договор за вас. Он показывает, где вас прижимают, и даёт текст, с которым не стыдно вернуться к заказчику. Стек — продолжение курса: MAX, Docling, RAG, LLM.»
