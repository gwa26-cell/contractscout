Услуги, подряд, поставка, аренда, NDA, IT

Проверьте любой договор и соберите свой черновик.

Общий каталог гражданских рисков плюс профиль IT: ответственность, оплата, расторжение, а для разработки — ещё IP, правки и ТЗ. Дальше — проект договора нужного типа в DOCX.

Сначала файл кладётся в локальный архив — его можно открыть и читать. ИИ вызывается отдельно и только по обезличенному тексту. Pinecone (если ключ задан) индексирует те же обезличенные фрагменты для поиска, полный договор там не хранится.

Не является юридической консультацией. Это черновик для переговоров и разговор с юристом.
