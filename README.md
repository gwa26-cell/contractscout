# ContractScout

Веб-сервис и опциональный MAX-бот: **проверка договоров** на узкие места и **черновик** нужного типа — услуги, подряд, поставка, аренда, NDA, заём, лицензия и IT.

По умолчанию файл остаётся на диске. В облачный ИИ (если задан ключ) уходит **обезличенный** текст: без ИНН, счетов, адресов, названий и ФИО сторон.

Не юридическая консультация. Черновик для переговоров и список вопросов юристу.

## Что умеет

- разобрать PDF/DOCX (Docling, иначе pypdf/python-docx);
- общий каталог гражданских рисков + IT-профиль;
- отчёт: индекс риска, цитаты, как чинить;
- собрать проект выбранного типа и скачать DOCX;
- оплата пакетов через ЮKassa; страницы [политики ПДн](/privacy) и [оферты](/offer).

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m contract_scout.web
```

Откройте http://127.0.0.1:8080

```bash
pytest -q
python -m contract_scout.bot   # нужен MAX_BOT_TOKEN
```

Деплой на VPS и ЮKassa: [docs/DEPLOY.md](docs/DEPLOY.md).
